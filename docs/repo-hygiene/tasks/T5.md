## The standard
Rubric A. Default is **delete**. A comment survives only by being operational
knowledge you cannot re-derive in ten minutes with the man page open, or a
load-bearing constraint on nearby code. Ratios are a smell detector, not a
target — do not stop because a number looks better, and do not cut a comment
that earns its place because the file is still above some percentage.
