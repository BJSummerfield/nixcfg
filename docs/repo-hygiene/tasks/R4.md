## G1 — internal drift (fix first; newest spelling is the reference)

**1. Hand-built `${pkg}/bin/x` vs `lib.getExe`/`lib.getExe'`.**
Signal: `grep -rn '\${[a-zA-Z0-9_.'"'"']*}/bin/' modules hosts`.
Reference (repo's own newest spelling, 15+ sites): `lib.getExe pkgs.foo` /
`lib.getExe' pkgs.foo "bin-name"`, newest at
`modules/local-llm/vllm-service.nix:17` (added 2026-09-01).
Divergent:
- `modules/devbox/container.nix:53` (`"${piWrapped}/bin/pi"`) — **same
  file** as `container.nix:45` which already uses `lib.getExe
  pkgs.claude-code`.
- `modules/local-llm/nixos.nix:214` (`"${pkgs.podman}/bin/podman"`) vs the
  same package via `getExe'` in the same module dir's newer file
  (`vllm-service.nix:17`).
- `modules/swaybg/home.nix:31`, `modules/swayidle/home.nix:11-12,45`,
  `modules/vikunja-server/nixos.nix:144` — all from the oldest file
  generation (swaybg/swayidle added 2026-01-05, predates `getExe` as house
  style).
Caveat: verify `pname` before converging — `piWrapped` (symlinkJoin) and
similar wrapper derivations still expose one `bin/<pname>`, so `getExe`
applies, but don't assume for every hand-built path.

**2. `sops.secrets.<name>` shape: dotted-path vs nested attrset for
siblings in one host block.**
Signal: in a host file, some secrets written `foo.sopsFile = X;` (one line)
next to siblings written `foo = { sopsFile = X; ... };`.
Cited: `hosts/redtruck/default.nix:56` (dotted) vs `:50-53`/`:57-61`
(nested) for the otherwise-identical secret family in the same block.
Replacement: nested-attrset form (majority shape, 7/8 entries in that file).
Overlaps T8/rubric F2 — don't duplicate the finding there, just flag per-file
here.

## G2 — external drift

**3. Per-secret `sopsFile = ../../secrets/hosts/<host>.yaml` repeated on
almost every entry vs `sops.defaultSopsFile`.**
Signal: `grep -c 'sopsFile = ' hosts/<host>/default.nix` > 1 with the same
RHS repeated.
Cited (old): `hosts/redtruck/default.nix` (6/7 secrets repeat the identical
path), `hosts/vps/default.nix:43,51,91` (3/4), `hosts/paynefield/default.nix
:17,25` (2/3). `defaultSopsFile` is unset anywhere in this repo
(`grep -rn defaultSopsFile .` → no hits).
Replacement, verified in pinned sops-nix source
(`.../s154mmk8ahvc71gq8xfkbzlk240yvniv-source/modules/sops/default.nix:203`,
used as the per-secret default at line 50): set `sops.defaultSopsFile`
once per host, drop the repeated per-secret line; keep an explicit
`sopsFile` override only where a secret genuinely lives elsewhere (e.g.
`restic-b2.yaml`). Shorter, typo-proof. Meets G3.
