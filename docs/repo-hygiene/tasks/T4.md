## 2. `mine.users.*` -> `mine.accounts.*`
User decision, 2026-09-04. This is the **system account registry** — uid,
password hash, ssh keys, NAS access. It sits one keystroke from the unrelated
`mine.user.*` home-manager namespace (43 modules declare into that one), and a
typo between them does not error: it silently defines an option nothing reads.
`mine.accounts` also describes it better — it is a registry of accounts.

Six files:
- `users/waktu.nix`, `users/sword.nix`, `users/sumriri.nix`, `users/jellyuser.nix`
  (each has one `mine.users.<name> = { ... };` block)
- `modules/users/nixos.nix` — the declaration (`options.mine.users`, ~:17) and
  its `cfg = config.mine.users` (~:9)
- `modules/filesystems/nas.nix` — reads it (~:17 `usersCfg`, and a second
  `options.mine.users` declaration at ~:77)

**Note the two declaration sites.** Both `modules/users/nixos.nix` and
`modules/filesystems/nas.nix` declare `options.mine.users` — the module system
merges them. Rename both or the build breaks in a confusing way.

Do **not** touch `mine.user.*` (singular), `users.users.*` (the NixOS option),
`users/` (the directory), or the `users` unix group. Grep carefully: `mine.users`
with the dot is the target; bare `users` is almost always something else.
