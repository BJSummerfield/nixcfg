# R1 — statix / deadnix / nixfmt (real numbers, 2026-09-04, nix 2.34.8)

**nixfmt**: repo already formats clean. `treefmt --fail-on-change` via the
existing `.#formatter` (nixfmt-tree/treefmt 2.5.0) on all 129 files: "formatted
129 files (0 changed) in 252ms". No fixes needed. Wire `nix fmt -- --fail-on-change`
(or a runCommand invoking the built formatter) as a check — free, and it's the
same formatter the devShell already ships.

**statix**: 41 findings / 24 files. `nix run nixpkgs#statix -- check .` ~0.1s
once the (tiny, cached) binary is built — negligible on a repo this size.
By code: `[20] repeated keys` ×25, `[4] assignment instead of inherit from` ×14,
`[3] assignment instead of inherit` ×1, `[10] empty pattern` ×1.
- **Fix (real, cheap, mechanical)**: all 15 inherit-suggestions — e.g.
  modules/pi-coding-agent/settings.nix:39,41,51-53,77,131 (`reasoning = m.reasoning;`
  → `inherit (m) reasoning;`), modules/backups/nixos.nix:94,97, terraria-server/nixos.nix:83-85.
  hosts/redtruck/filesystems.nix:1 empty `{ ... }:` → `_:`.
- **Noise — exclude via `-i`/statix.toml, don't hand-fix**: `[20] repeated keys`
  firing on hosts/*/hardware-configuration.nix (elitebook, paynefield, redtruck,
  t495) — these are nixos-generate-config output carrying "Do not modify this
  file!" as line 1; editing to appease the linter fights the generator.
  Also noise on modules/devbox/container.nix:108,148,160,274 and
  modules/niri/home.nix:30 — deliberately grouped `xdg.*`/`boot.*`-style
  assignments split for readability across a long file; merging them per
  statix's suggestion doesn't improve anything the rubric cares about (B-audit,
  not literal-warning-count). Recommend `statix.toml` `disabled = []` is fine,
  but add `-i 'hosts/*/hardware-configuration.nix'` at the check-invocation level.

**deadnix**: 19 findings / 15 files, all "unused lambda argument/pattern"
(module `{ pkgs, ... }:`-style args never referenced). ~0.1s to run.
- Same 4 hosts/*/hardware-configuration.nix generated files reappear (unused
  `pkgs`) — exclude the same glob; don't edit generator output.
- The rest (modules/devbox/nixos.nix:22, modules/_1password/nixos.nix:14/47/48,
  modules/users/nixos.nix:10/98/115, modules/filesystems/nas.nix:111/140, etc.)
  are real and safe to fix — no NixOS module-arg false positive here since
  every flagged file also has a `...` catch-all, so dropping the unused named
  arg loses nothing. No special flags needed (`-l`/`-L`/`-_` not required);
  just add `--exclude 'hosts/*/hardware-configuration.nix'`.

**Wiring recommendation**: add all three as flake `checks.<system>.*`
derivations (each a `pkgs.runCommand` with statix/deadnix/nixfmt-tree as
`nativeBuildInputs`, `src = ./.` filtered to exclude `.git`), not a separate CI
step — `nix flake check` is already the single gate CI runs, so this keeps
local `nix flake check` == CI with no drift. Cost is ~0.3-0.5s total, invisible
against the current ~3min CI. Also add `statix` + `deadnix` to the devShell
(nixfmt is already there) so `nix develop` matches what CI enforces.
